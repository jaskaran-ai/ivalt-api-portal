# Rename `IVALT_SECURITY_TOKEN` to `IVALT_API_KEY` everywhere + remove fake `token` header

## Goal
Use one consistent name: **`IVALT_API_KEY`** as the env var, and pass it as `x-api-key` header only. Remove all references to a separate `token` header and replace `security token` / `SECURITY_TOKEN` / `IVALT_SECURITY_TOKEN` with `IVALT_API_KEY`.

## Source of truth
`src/lib/ivalt.ts:26` and `:50` — actual header sent:
```
{ "Content-Type": "application/json", "x-api-key": SECURITY_TOKEN }
```
There is **no** `token` header.
